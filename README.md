# TaksiDefter Android Releases

This public repository contains only signed Android APK release files and release notes for the TaksiDefter app.

The application source code remains in the private `taksi-defter-android` repository.

## Install and update

Download the APK from the latest release and install it using Android's standard package installer. Android will ask for confirmation before installation.

Do not install an update unless it is signed with the same signing key as the currently installed app.
